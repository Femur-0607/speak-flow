## 1. TBLT (Task-Based Language Teaching)의 핵심 원리

과업 중심 언어 교수법(TBLT)은 기존의 문법 중심 암기(PPP 모델: Presentation-Practice-Production)를 전면 수정하여, **"실제 현실 세계의 의미 있는 과업(Real-world Task)을 달성하는 과정에서 언어가 자연스럽게 습득된다"**는 원리를 증명한 현대 응용언어학의 표준 프레임워크입니다.

```
┌────────────────────────────────────────────────────────┐
│ 1. Pre-Task (과업 준비)                                │
│    - 상황적 맥락 활성화 (도쿄 시부야 카페 카운터 앞)   │
│    - 핵심 어휘 및 관용구(Chunk) 사전 인출 준비        │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ 2. Task Cycle (과업 수행 및 음성 상호작용)             │
│    - [목표]: "얼음 적게 넣은 아이스라떼 포장 주문하기" │
│    - 점원과 실시간 발화 상호작용 수행 (STT 마이크 입력)│
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ 3. Post-Task / Language Focus (언어 형태 집중 및 성찰) │
│    - 발음 정확도 분석 및 불일치 단어 교정              │
│    - Native Polish: 원어민식 세련된 뉘앙스 대조 학습   │
└────────────────────────────────────────────────────────┘
```

## 2. 화용론적 실패(Pragmatic Failure) 방지

제니 토마스(Jenny Thomas)의 연구에 따르면, 외국인이 현지에서 겪는 가장 큰 문제는 "문법 오류"가 아니라 **"문화적·화용론적 무례함이나 어색함(Pragmatic Failure)"**입니다:

* **영어권 사례:** 
  * 식당에서 *"Give me water"*라고 하면 문법은 맞지만 명령조로 들려 불쾌감을 줌.
  * 현지인들은 거의 100% *"Could I get some water, please?"* 또는 *"Can I have...?"*라는 간접 공손 표현(Indirect Politeness)을 구사함.
* **일본어 사례:** 
  * 편의점 직원이 봉투 필요 여부를 물었을 때 *"No"*나 *"いいえ(이이에)"*라고 잘라 말하면 매우 차갑게 느껴짐.
  * 현지에서는 손을 살짝 저으며 *"大丈夫です (다이죠부데스, 됐습니다/괜찮습니다)"*라고 부드럽게 거절하는 것이 화용론적 표준임.

SpeakFlow의 상황별 팁과 대안 표현(Alternatives)은 이러한 현지 문화적 맥락(Pragmatic Nuance)을 직접 전수하여, **현지인에게 환영받는 자연스러운 말투**를 갖추도록 지원합니다.
