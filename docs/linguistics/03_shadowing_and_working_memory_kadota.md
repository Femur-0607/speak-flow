## 1. 배들리(Baddeley)의 작업 기억(Working Memory)과 음운 루프

영국 인지심리학자 앨런 배들리(Alan Baddeley)의 모델에 따르면, 인간의 뇌에서 언어 정보를 실시간으로 처리하는 핵심 장치는 **음운 루프(Phonological Loop)**입니다:

```
[외부 음성 유입]
       │
       ▼
 ┌───────────────────────────┐
 │ 음운 저장소 (Inner Ear)   │ ─── 1.5~2초간 음성 신호 일시 보존
 └─────────────┬─────────────┘
               │
               ▼
 ┌───────────────────────────┐
 │ 조음 리허설 (Inner Voice) │ ─── 뇌 속에서 소리 내어 되뇌며 망각 방지
 └───────────────────────────┘
```

* 모국어 화자는 소리를 듣는 즉시 의미로 변환되지만, 외국어 학습자는 소리 자체를 뇌가 분석하느라 **음운 루프 용량이 100% 포화**되어 의미를 파악하거나 대답할 여유가 사라집니다.

## 2. 카도타 슈헤이(門田 修平)의 쉐도잉 뇌과학 원리

일본 간사이 대학의 카도타 슈헤이 교수는 수십 년간 쉐도잉의 신경언어학적 효과를 검증했습니다:

### (1) 청각-운동 연합(Auditory-Motor Coupling)의 활성화
* 쉐도잉은 들려오는 원어민 음성을 1~2음절 뒤에서 그림자처럼 즉시 따라 말하는 훈련법입니다.
* 베르니케 영역(Wernicke's area, 언어 청각 처리)과 브로카 영역(Broca's area, 언어 운동/조음 생성)을 연결하는 활꼴 다발(Arcuate Fasciculus) 신경망을 강력하게 자극합니다.

### (2) 모국어 번역 회로의 차단
* 원어민 음성을 들으면서 동시에 내 입으로 발음해야 하므로, **"들음 → 한국어로 번역 → 다시 외국어로 작문"**하는 악습관을 물리적으로 차단합니다.
* 뇌는 입력된 외국어 소리를 곧바로 조음 운동으로 직결하는 **"외국어 직통 신경망"**을 형성합니다.

### (3) 운율(Prosody)과 음운 자동화
* **일본어:** 고저 악센트(Pitch Accent, 高低アクセント - 예: 橋(하시, 다리) vs 箸(하시, 젓가락))와 장음(長音)/촉음(促音)의 미묘한 박자를 몸으로 체득.
* **영어:** 연음(Linking), 탈락(Reduction), 강세 기반 박자(Stress-timed rhythm)를 무의식적으로 복제.

## 3. SpeakFlow의 3단계 점진적 쉐도잉 루틴

```
[1단계: Listen] 원어민 표준 음성 2~3회 청취 (리듬과 악센트 파악)
      │
      ▼
[2단계: Shadow] 마이크를 켜고 0.5초 시차로 즉시 따라 말하기 (STT 포착)
      │
      ▼
[3단계: Compare] 목표 문장 음운 vs 내 발화 텍스트 1:1 정밀 일치도 대조 & 피드백
```

이 루틴을 거치면 귀로 들은 음소(Phoneme)가 조음 기관(혀, 입술)의 근육 기억(Muscle Memory)으로 각인되어, 실제 현장 상황에서 억양과 발음이 자연스럽게 터져 나오게 됩니다.
